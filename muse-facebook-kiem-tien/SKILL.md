# Muse × Facebook Monetisation

Core principle: a Page earns money only when two things run in parallel — steady content so the algorithm distributes it, and a mechanism that turns views into money. Muse handles the content and the operations; the user keeps the accounts, films/edits and presses publish. Never ask the user for passwords or verification codes.

## The 5-step workflow

### 1. Lock the niche and the content ratio
Define what the Page is about and who it is for. Starting monthly ratio: entertainment ~50% · tips/value ~35% · selling ~15% — sales back-to-back makes people unfollow.

### 2. Monthly plan, written week by week
Build the month's frame from the niche and ratio, then detail each week: Reels scripts, text posts, sales posts with their products. Table: day · format · topic · product.

### 3. Produce the content
**Reels scripts — 3-layer hook, visual + text lead** (viewers often watch muted): first frame = the payoff · text 3–7 words, big, high-contrast · spoken payoff inside ~2 seconds. Body 15–45s, one idea, strongest moment near the end. Sales posts name the problem solved, not the price. Original content only; cross-post from the master edit, never a competitor watermark.

### 4. Publish and pin the affiliate links
Publish on schedule; pin a comment with the affiliate link + a clear disclosure right after posting. Reply early to good comments — a good comment can be answered with a new Reel.

### 5. Read Business Suite numbers weekly
Diagnose in order: **first-3-seconds retention** → completion rate → engagement. A first-3s leak = hook fault; a mid-video drop = pacing. Clone what retains best.

## Amazon affiliate packaging (summary)
Register the Page's URL under Sites in Amazon Associates BEFORE attaching links. Disclose every commission post clearly (#affiliate). Build real content first.

## Monetisation on Facebook (summary)
Content Monetization (Meta's unified programme) is invitation-based — check the Professional Dashboard. The age check reads the PERSONAL profile's date of birth, not the Page's. Amazon commissions run from week one.

## What Muse does / what the user does
Muse: plan, scripts, captions, sales posts, affiliate packaging, number-reading. User: creates the Page, films/edits, publishes, checks eligibility.
